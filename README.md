# YTD - YouTube, Facebook & All Video Downloader APK

**YTD** is a high-performance Android application built to download videos and audio from YouTube, Facebook, TikTok, Instagram, Twitter/X, and any generic web page.

## Key Features
- 🎬 **Multi-Site Downloader**: High-speed video extraction for YouTube, Facebook, TikTok, Instagram, Twitter/X, and more.
- 🌐 **Built-in Web Sniffer Browser**: Browse any video site and automatically detect downloadable stream URLs (`.mp4`, `.m3u8`, `.webm`).
- ⚡ **Multi-Quality Support**: Download in 1080p Full HD, 720p HD, 480p SD, or extract MP3 audio.
- 📁 **Download Manager**: Background downloads, progress notifications, file management, and instant playback.
- 🎨 **Modern Dark Aesthetics**: Sleek dark mode UI with interactive visual cards and quick clipboard auto-paste.

## Building from Source (Termux / Linux)
Run the automated build script:
```bash
./build_apk.sh
```
The compiled signed APK will be output to `ytd.apk`.
